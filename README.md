# Просто песня 🎵

Telegram-бот, который скачивает музыку из Яндекс Музыки и присылает MP3 прямо в чат.

👉 **[@singsongnobot](https://t.me/singsongnobot)**

---

## Как пользоваться

Просто напиши название трека — бот найдёт и пришлёт файл.

**Примеры запросов:**

```
Земфира Хочешь
```
```
Кино - Группа крови
```
```
Linkin Park Numb
```

Бот ищет по первому совпадению в Яндекс Музыке и отправляет MP3.
